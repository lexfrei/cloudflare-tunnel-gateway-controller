# HTTPRoute clause audit (HR-*)

Audited at `sigs.k8s.io/gateway-api v1.6.1` (originally at v1.5.1; the v1.6.0 tag diff carries NO Standard-channel HTTPRoute schema changes — the CORS repeated-filter CEL of kubernetes-sigs/gateway-api#4639 was already in v1.5.1, and the retry validation of #4907 is experimental-only, so the Standard HTTPRoute CRD still has no `retry` field; the HR-26..HR-39 retry rows were re-audited against v1.6.2 when the proxy gained Experimental-channel retry support) and the in-process L7 proxy data plane (`internal/proxy`, `internal/ingress`, `internal/controller`). All L7 routing/matching/filtering/error semantics are implemented in the proxy + controller, NOT by Cloudflare Tunnel (whose ingress document only feeds the Cloudflare dashboard — the vendored cloudflared fork's `OverrideProxy` hook funnels all traffic through `internal/tunnel/origin.go` → the proxy).
